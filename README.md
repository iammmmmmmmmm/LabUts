# BOOKSTORE - Aplikasi Toko Buku Online

## Deskripsi
BOOKSTORE merupakan aplikasi toko buku online berbasis web yang dibuat untuk memenuhi tugas UTS Pemrograman Web.

Aplikasi ini dirancang untuk membantu admin mengelola data buku, stok, pemesanan, transaksi, dan laporan penjualan.

## Fitur Aplikasi
1. Login Admin
2. Dashboard Admin
3. Informasi dan Pengelolaan Stok Buku
4. Pemesanan dan Checkout Buku
5. Tracking Pengiriman Pesanan
6. Laporan Pemesanan
7. History Transaksi

## Teknologi
- HTML
- CSS
- JavaScript
- Local Storage
